## Changes and exactness

Terrain identity now uses Bevy's `Children` for ordinary discovery. The world-wide `parent_links`, `child_links` and `untracked` stores are removed. Cached semantic facts remain only on terrain dependency paths, including refused candidates, so Visibility, Children, readiness/patch markers and unchanged chunk keys do not retrace dependent terrain meshes. Primitive membership remains part of invalidation. The production-extractor contract is documented on `identities_shared`, rather than its test helper. Results keep the cache's own Arc; a consumer must retain its previous snapshot across the next fetch to use pointer equality as a freshness test.

A deferred ChildOf lifecycle check runs after Bevy 0.19's queued relationship hook. The append fast path tests the parent's last child; the fallback scans only that parent's siblings. Metrics count both paths, actual inspected siblings and the maximum sibling list. A Children discard observer also checks its former siblings after replacement/removal, covering hook-skipped backlink removal without a ChildOf insertion. Missing backlinks are exceptional state only, with an entity/parent/reason warning once per episode and a recovery request counter. Recovery uses the shared ancestry memo and diffs the snapshot, without independently retracing every ordinary object's ancestry. Late installation seeds exceptions from already memo-read mesh paths and checks the raw hierarchy, including filtered parents. Ordinary streaming does not retain a world relationship index.

LOD liveness polling now covers only empty ancestry nodes with no journal-observed marker. A coverage-bearing orphan is observed, so object-only frames do not reevaluate it. All readiness/visibility decrement paths use checked subtraction, error logs and `lod/visibility/desyncs`; there is no release wrap. Query simplification keeps the original default-disabler domains. Tests live in `streaming/lod/visibility/tests.rs`. Both indices warn once per consecutive lost-journal episode and still recover whenever exactness requires it.

`--terrain-audit` defaults off. In release, disabled installs no audit resource/publisher and performs no audit clock read, comparison or allocation. Enabled checks use independent one-second wall-clock cadences and publish `terrain/audit/{identity,lod}/{checks,desyncs}` through `--profile-output <dir>`'s `cpu-spans.json`. Errors log `terrain audit desynchronization`. Clustered builds audit the production extraction cache; stock builds install an opt-in identity consumer. The LOD comparison includes actual ECS Visibility except intentional held overrides. Debug builds retain exhaustive assertions. Audits do not change selection, readiness, visibility or original idle legacy behavior.

## Independent review and explicit decisions

Independent GPT-6-Astra review found no Critical issue. Its Children-replacement discovery finding and visibility-output audit gap were reproduced red, fixed and covered by the green engine/workspace suites. The author reviewed the worker diffs; workers ran no Cargo or engines. A DeepSeek L7 attempt failed with `Invalid API key · Fix external API key`, zero tokens; the independent Claude fallback completed that search.

The event-local detector was extended to Children discard because replacement/removal can remove backlinks without a ChildOf event. The release audit's actual-output comparison was treated as required checker correctness; held external changes remain exempt. Wrong event bounds would cost sibling-local work, and wrong override exemptions could cause false alarms or miss output corruption; route counters and randomized compatibility tests check these boundaries.

Lead decision (cluster demo thread, 2026-10-21): callers must keep Bevy's documented relationship invariant for eventless `Children::collection_mut_risky()` edits, since Bevy's Children docs forbid direct manipulation. This confirms the contract used during the completed checks and routes; it is no longer an unanswered scope assumption. Hook-skipped `ChildOf` insertion and `Children` replacement/removal remain covered exactly, including wholly uncovered trees. A caller that directly edits Children without a lifecycle event must maintain or repair the relationship invariant before streaming consumes the hierarchy. Otherwise a newly covered hidden mesh can be missed. No global scan/index was added to diagnose such invalid input. The ruling changes documentation only; the verified source and immutable executable are unchanged.
