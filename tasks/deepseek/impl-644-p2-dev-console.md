# Goal
Build the first slice of a Skyrim-style developer console for the engine (upstream issue #88): the backtick key opens and closes it and pauses the game; a command registry with `help`, `clear`, clear errors with a "did you mean" suggestion, and Tab autofill; the existing debug keys (V, F3, T, E) also reachable as commands, with the keys still working.

- The design is settled; follow it. It is in `C:/Users/Brannock/.claude-deepseek/agents/runs/research-643-p2-dev-console-design.1/report.md` (read sections 1-7 and Risks before you start). Its file:line references are for this checkout. Decisions on top of that report:
  1. **Input gate**: opening the console sets `CursorCapture::Released` (most input systems already bail when not captured). Gate the three that do not: `toggle_collision_debug_system` (physics.rs ~1538, registered ~359) and `fly_camera` (app.rs ~1878, registered at app.rs ~169; leave `capture_acceptance_screenshot` ungated) with `.run_if(console_closed)`; in `cursor_lifecycle_system` (physics.rs ~1743) skip the focus/Escape/left-click block while the console is open, but keep the `CursorOptions` write unconditional. `console_closed` takes `Option<Res<ConsoleState>>` and returns true when the resource is absent, so the existing partial test apps keep working.
  2. **Pause**: `Time<Virtual>::pause()` on open, `unpause()` on close, but only if it was not already paused at open (`was_paused`). Call `clear_motion_state` (physics.rs ~914) at the open edge, like the Escape path does, so a held key cannot resume as a stuck walk. On close, restore the cursor capture the player had before opening.
  3. **Toggle and text**: console systems run in `PreUpdate` after `bevy::input::InputSystems`. Toggle on `ButtonInput<KeyCode>::just_pressed(KeyCode::Backquote)`. Text from `MessageReader<KeyboardInput>`: pressed events only; insert `ev.text` for printable input; Backspace, Enter (run), Tab (autofill), Escape (close). The backtick that opens or closes the console must never land in the buffer.
  4. **Registry**: `ConsoleCommand { name, aliases, usage, help, handler }`, handler `Box<dyn Fn(&mut World, &[&str]) -> Result<String, String> + Send + Sync>`; `ConsoleRegistry` resource with `register`, `get` (name or alias, case-insensitive), sorted `names()`; an `AppConsoleExt::add_console_command` trait so each plugin registers its own commands. Dispatch from one exclusive system. Parsing is `split_whitespace`; no quoting.
  5. **Commands in this slice, no more**: `help` (lists every command with usage and its one-line help; `help <name>` shows one), `clear`, `noclip` (alias `v`), `collision` (alias `f3`), `tankard` (alias `t`), `grab` (alias `e`). Each key-bound command runs the same effect code as its key: split the effect bodies out of `toggle_mode_system`, `toggle_collision_debug_system` and `world_tankard_input` into effect systems; the key systems call them on their key, the commands call them with `world.run_system_once(..)`. A command whose plugin is not in this run (e.g. `tankard` with no `TankardVisuals`) returns an `Err` message, never panics.
  6. **Unknown command**: message `unknown command "noclup", did you mean "noclip"? Type "help" for the list.` Suggestion from a small Levenshtein in console.rs, distance <= 2; no suggestion line part when nothing is close.
  7. **Autofill**: Tab completes the first token only: one match replaces it with the name plus a space; several extend to their longest common prefix, and if that adds nothing, list the candidates in the scrollback.
  8. **UI**: one absolute, bottom-anchored root `Node` (full width, about 40 % height, translucent `BackgroundColor`) with two `Text` children: the last ~15 scrollback lines and the input line `> buffer`. Show and hide with `Node.display`. Copy the style of the `NoclipOverlay` (physics.rs ~1633). Scrollback capped at 200 lines. No history recall (Up/Down) in this slice.
  9. Keep the parsing, completion, Levenshtein and scrollback logic in pure functions that the tests call without `bevy_ui`.
- `ConsolePlugin` is added once in app.rs for every run.
