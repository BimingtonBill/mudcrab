# Goal
What does the Skyrim roleplay (RP) community actually use and need from multiplayer, and where do current tools fail them?

# Context
- Background: Mudcrab is an open-source (MIT/Apache-2.0 dual-licensed) reimplementation of the Skyrim engine in Rust with the Bevy game engine. Players convert their own legally owned Skyrim Special Edition data, then play it in the new engine (it does not run the original executable). Multiplayer is on its long-term roadmap ("native co-op: ECS entity replication over UDP/WebSockets; sync player transforms, animations, combat and world deltas"). The goal of this research: design multiplayer that serves the Skyrim ROLEPLAY community and builds on existing Skyrim multiplayer projects instead of starting from zero.
- Cite every claim with URLs; prefer primary sources (official sites, GitHub repos, docs, wikis, developer posts, Discord/Reddit announcements by the projects). Give dates; flag anything older than 2 years as possibly stale.
- Cover: Skyrim RP servers and communities (e.g. Keizaal Online, SkyMP roleplay servers, Skyrim Together RP groups, any "Skyrim RP" Discord networks), their size and rules; what features RP servers add on top of the base multiplayer mod (character persistence, character sheets/whitelists, in-character vs out-of-character chat, proximity/emote chat, /me, dice, custom races/factions, economy and jobs, player housing, admin/GM tools to spawn NPCs or run events, persistent world, permadeath rules, lore-friendly content); recurring complaints (desync, mod limits, crashes, NPC/quest breakage, griefing, server costs, update breakage after Skyrim patches, anti-cheat); how other games' RP communities are served (GTA V FiveM, Red Dead RedM, Conan Exiles, Mount & Blade Persistent World, Garry's Mod DarkRP, ESO RP guilds, TES3MP RP servers) and which of their tools Skyrim RPers ask for.
- Sources: community Discords' public pages, Reddit (r/skyrimmods, r/SkyrimTogether, r/skymp, RP subreddits), forums, server listing sites, YouTube/blog write-ups, project FAQs.

# Done when
- A ranked list of RP needs, each backed by at least one community source, and the main failure points of current Skyrim MP for RP.

# Report
- "Top needs" ranked, each with sources and how strongly supported; then "Pain points with current Skyrim MP"; then "Proven tools from other RP communities" (FiveM etc.) with what makes them work (e.g. FiveM's server-side resource scripting). Under 1300 words.
